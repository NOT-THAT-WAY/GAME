# WwiseProject

Ce dossier recevra le projet Wwise après la gate de compatibilité Unity 6.3 / Wwise 2025.1.4. Ne pas créer trois projets séparés : une personne l'intègre sur une branche, Windows le valide, puis les autres tirent le même projet.

Les `.wproj`, `.wwu` et `Originals/` prêts à l'emploi sont versionnés. Les sessions DAW, prises brutes et masters haute définition restent dans `ExternalAssets/Audio/<AssetId>/` via DVC. Les caches et SoundBanks générées sont ignorés.
