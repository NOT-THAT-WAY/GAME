# _Project

Code et contenu appartenant au jeu, organisés par feature. Les packages et assets tiers restent séparés.

Dossiers initiaux : `Runtime` pour le code de jeu indépendant de l'éditeur et `Editor` pour les outils de l'équipe. Ajouter ensuite `Core`, `Player`, `Pivot`, `Maze`, `Audio` et `UI` au rythme des prototypes.
