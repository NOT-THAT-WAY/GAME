# Game assets

Select the profile matching the declared Unity, Unreal, Godot or glTF target. Record engine,
importer and exporter versions. Define budgets per LOD, materials, texture memory, bones,
influences and colliders before detail work.

Validate scale, orientation, pivot, silhouette at gameplay distance, topology, normals, UVs,
tangents, lightmap policy, materials, collision, LOD/Nanite policy and skeleton/clips when present.
Keep render meshes and collision intent explicit.

Export with recorded settings, reimport independently, then import into the exact target project.
Capture warnings and measurements. Axis presets and a clean Blender reimport are preliminary only.
