# Point de compatibilité Kimi K3

Ce nom est conservé uniquement parce que certains cas d’étude historiques le référencent. Pour
tout nouveau travail, l’autorité est `AGENTS.md` et le manuel est `AGENT_HANDBOOK.md`.

Créer désormais un projet générique :

```bash
python3 workflows/tools/create_team_project.py --help
python3 workflows/tools/validate_team_project.py --help
```

Les anciens projets Kimi restent des exemples de provenance. Ils n’imposent ni préfixe, ni style,
ni seuil, ni structure de livraison à un nouveau projet.
