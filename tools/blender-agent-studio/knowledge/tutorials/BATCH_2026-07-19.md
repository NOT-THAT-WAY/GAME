## Point d'entrée production

Le document à utiliser pour concevoir une nouvelle scène ou un workflow MCP est le
[Playbook animation Blender](ANIMATION_WORKFLOW_PLAYBOOK.md). Il contient :

- le choix de la recette selon le type de plan;
- la séparation références/source asset/work asset/shot/output;
- l'audit minimal d'un asset existant;
- une hiérarchie de contrôle commune;
- les règles d'interpolation par fonction;
- les gates professionnels;
- six workflows contrôlés proposés pour Blender Studio.
