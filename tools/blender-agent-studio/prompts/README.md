# Prompts de départ

Ces patrons rendent une demande exploitable par n’importe quel membre de l’équipe. Ils complètent
`AGENTS.md` ; ils ne le remplacent pas.

| Besoin | Prompt |
|---|---|
| modèle ou objet réutilisable | `AGENT_ASSET_BUILD.md` |
| prop/personnage de jeu | `AGENT_GAME_ASSET.md` |
| rig, mécanisme ou animation | `AGENT_RIG_ANIMATION.md` |
| environnement ou procédural | `AGENT_ENVIRONMENT.md` |
| still, plan ou film | `AGENT_SCENE_TRIAL.md` |
| vérifier une installation | `AGENT_READINESS_CHECK.md` |

Remplacer tous les chevrons. Toujours déclarer cible, version, échelle, usage, invariants, budgets,
formats et preuves attendues. Les assets sont référencés par ID du catalogue et restent locaux.
