# Contexte et usage

Blender Team Studio est un noyau d’équipe clonable. Il organise la création 3D, les décisions et
les preuves ; Blender reste l’outil natif de modélisation, animation et rendu.

Commencer par :

- `README.md` et `GETTING_STARTED.md` pour installer le clone ;
- `AGENTS.md` pour les règles obligatoires ;
- `AGENT_HANDBOOK.md` pour produire ;
- `catalog/capabilities.json` pour savoir ce qui est automatisé ou seulement contractualisé ;
- `app/README.md` pour l’interface locale optionnelle.

Le dépôt n’embarque aucun asset binaire. L’interface peut afficher son catalogue même lorsqu’un
fichier est absent, puis les membres autorisés le matérialisent localement par SHA-256.
