# Repository routing

Load only what the task needs.

- Authority and process: `AGENTS.md`, `AGENT_HANDBOOK.md`, `standards/CORE_PRODUCTION_STANDARD.md`.
- Domain standards and profiles: `standards/*.md`, `standards/profiles/*.json`.
- Asset discovery: `catalog/assets.json`, `asset-families.json`, `blender-scenes.json`.
- Capability maturity: `catalog/capabilities.json`; optional upstreams: `catalog/third-party.json`.
- Physics: `knowledge/PHYSICAL_WORLD_OBJECT_RULES.md`, evaluation rules and object contracts.
- Style: `knowledge/STYLE_PROFILES.md`, `knowledge/style-profiles/`.
- General craft: `knowledge/BLENDER_PRODUCTION_PLAYBOOK.md` and tutorial playbooks.
- Controlled operations: `workflows/catalog/`, `workflows/scripts/`, `workflows/tools/`.
- New project records: `projects/team/`; local binaries: ignored `local_work/` and `local_assets/`.
- Historical examples: named folders in `projects/`, `library/`, `audits/` and `knowledge/tutorials/`.

Historical names, tokenized paths and scores are provenance, not defaults or current proof.
